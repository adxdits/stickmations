# Framation

Framation is a desktop 2D stick-figure animation software.

## Architecture

- `frontend/` — Angular (TypeScript) editor UI.
- `core/` — Java animation engine, built with Gradle. Independent of the frontend.
- `desktop/` — Desktop integration (packaging/launcher), placeholder for now.
- `docs/` — Project documentation.

This is currently a minimal foundation with no animation features implemented yet.
